# Projects

One Markdown file per project, from [`templates/project.md`](../templates/project.md).

A project page is the rolled-up, continuously-updated state of a research
thread — supported conclusions, open questions, reagents in use — each claim
citing the experiment IDs that back it. It links out to `Experiments/`,
`Protocols/`, and `Samples/`; it doesn't duplicate their content.

To start one, copy the template:

```bash
cp templates/project.md Projects/PRMT5-ChromatinRelease.md
```

and fill in the front matter.
